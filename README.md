## 📚 Topics Covered

This repository contains organized notes covering the complete lifecycle of array manipulation:

* 🟢 **Basics:** Array creation (`1D`, `2D`, `3D`), data types, and attributes (shape, size, ndim).
* 🟡 **Indexing & Slicing:** Accessing specific elements, boolean masking, and fancy indexing.
* 🔵 **Array Manipulation:** Reshaping, flattening, concatenating, and splitting arrays.
* 🔴 **Mathematical Operations:** Element-wise operations, statistical methods (mean, median, variance), and aggregate functions.
* 🟣 **Advanced Concepts:** Broadcasting rules, linear algebra (`np.linalg`), and random number generation (`np.random`).
